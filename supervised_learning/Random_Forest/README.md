# Random Forest from Scratch

This project implements **Random Forest** from scratch using **NumPy**.

Random Forest is an **ensemble learning algorithm** that combines the predictions of many Decision Trees to produce a more accurate and robust model. Instead of relying on a single tree, it trains multiple trees using **Bootstrap Sampling**, **Random Feature Selection**, and **Majority Voting**.

The primary objective of this implementation was to understand how ensemble learning reduces overfitting while improving generalization by building directly on a Decision Tree implementation developed from scratch.

---

# Objective

Given a dataset

| Height | Weight | Class |
|--------|--------|-------|
| 2 | 3 | Cat |
| 3 | 4 | Cat |
| 4 | 3 | Cat |
| 5 | 6 | Cat |
| 6 | 7 | Dog |
| 7 | 8 | Dog |
| 8 | 8 | Dog |
| 9 | 10 | Dog |

train multiple Decision Trees on different bootstrap samples and combine their predictions through majority voting to classify new observations.

---

# Mathematical Background

Random Forest is based on the idea that a collection of weakly correlated Decision Trees can produce a stronger overall model.

Rather than training a single tree on the entire dataset, each tree receives a different view of the data.

---

## Bootstrap Sampling

Each tree is trained on a bootstrap sample generated by sampling **with replacement**.

```text
Original Dataset

↓

A A C D D E G H
```

Some samples appear multiple times while others may not appear at all.

Each Decision Tree therefore learns from a slightly different dataset.

---

## Random Feature Selection

At every split, the tree considers only a random subset of features.

For a classification problem, a common heuristic is

```text
Number of Features

=

√(Total Features)
```

This encourages trees to learn different decision boundaries instead of repeatedly selecting the same dominant features.

---

## Information Gain

Each Decision Tree still selects the best split by maximizing Information Gain.

```text
Information Gain

=

Parent Entropy

-

Weighted Child Entropy
```

The only difference is that Information Gain is computed using only the randomly selected subset of features.

---

## Majority Voting

After all trees have been trained, every tree independently predicts the class of a new observation.

```text
Tree 1 → Dog

Tree 2 → Dog

Tree 3 → Cat

Tree 4 → Dog

Tree 5 → Dog
```

The final prediction is simply

```text
Dog
```

since it receives the majority of votes.

---

# Algorithm

1. Generate a bootstrap sample.
2. Randomly select a subset of features at every split.
3. Train a Decision Tree.
4. Repeat for all trees.
5. Collect predictions from every tree.
6. Return the majority vote.

---

# Implementation Notes

The implementation reuses the previously developed **Decision Tree** implementation.

During training

```python
for _ in range(n_trees):

    x_bootstrap, y_bootstrap = bootstrap_sampling(X, y)

    tree = DecisionTree()

    tree.fit(
        x_bootstrap,
        y_bootstrap,
        random_forest=True
    )

    forest.append(tree)
```

Prediction simply gathers every tree's prediction.

```python
predictions = []

for tree in forest:

    predictions.append(tree.predict(x_new))
```

The predicted class is the majority vote.

# Connections

While implementing Random Forest, I found that it extends Decision Trees rather than replacing them.

Instead of modifying the tree learning algorithm itself, Random Forest improves performance by introducing randomness into the training process and combining many independently trained trees through majority voting.

The implementation connects several concepts studied previously:

- Decision Trees
- Entropy
- Information Gain
- Bootstrap Sampling
- Ensemble Learning
- Bias-Variance Tradeoff
- Majority Voting
- Probability and Statistics

Random Forest demonstrates how combining many individually imperfect models can produce a significantly stronger predictor than any single model.
